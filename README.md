# JIMS Greater Noida - Basic Landing Page

A simple, clean, and straightforward landing page for **JIMS Engineering Management Technical Campus (JEMTEC)**, Greater Noida ([https://www.jimsgn.org/](https://www.jimsgn.org/)).

Designed to be **basic, clean, and easy to explain in a technical interview**:
- No heavy frameworks (No React, Tailwind, or Bootstrap)
- No complex or distracting animations (clean, static, readable styling)
- Written in plain HTML5, standard CSS, and basic JavaScript

## 💡 What to Explain in the Interview

1. **HTML**: Clean sections using semantic tags (`<header>`, `<nav>`, `<section>`, `<form>`, `<footer>`), labeled inputs, and organized structure.
2. **CSS**: Simple Flexbox for navigation and hero, CSS Grid for courses and facilities, simple buttons, and a media query for mobile screens.
3. **JavaScript**:
   * Mobile menu toggle (`classList.toggle('show')`)
   * Course filter tabs (reads `data-category` and sets `card.style.display`)
   * FAQ toggle (opens/closes answer on question click)
   * Form check (validates name & 10-digit phone, shows simple alert)
